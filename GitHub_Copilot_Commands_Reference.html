6. Discover available commands in your VS Code

  1. Open VS Code and Copilot Chat (typically Ctrl+Alt+I where configured).
  2. Type / to see slash commands.
  3. Type # to see context, files, folders, symbols and tools.
  4. Type @ to see available participants or agents.
  5. Use the Chat tool picker to inspect enabled tools.
  6. Run a short example and verify generated code before accepting changes.

Trainer tip: Demonstrate /plan, #codebase, file references, #selection, /explain, /fix and /tests first.
